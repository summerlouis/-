# Bao.Dumpling 点餐与经营管理系统

包子、饺子、粥品餐厅的双语（中文 / 法文）点餐系统。

## 页面入口

- `index.html`：顾客自助点餐
- `pos.html`：人工收银 POS
- `kitchen.html`：厨房接单屏
- `admin.html`：管理员后台
- `owner.html`：历史数据
- `dist/`：可直接部署的静态网站版本

## 功能

- A 类包子、B 类饺子、C 类粥品编码
- 馅料与蒸 / 煎 / 煮做法选择
- 堂食 / 打包、购物车、模拟付款与取餐号
- 厨房订单状态和制作方式显示
- 管理员密码、订单删除与本地操作记录
- 中法双语界面

> 当前为浏览器本地演示版：同一设备的多个页面会通过浏览器本地储存联动；跨设备实时订单需要后续接入服务器数据库。
