# 每日交班对账

后台“交班对账”和 POS 页底部的可展开入口提供本店整日累计对账。按所选日期和时区统计实际收款/退款发生时间，不按最初下单日归集；默认 Europe/Paris，可调整。

应有现金（分）=期初备用金+现金实收−现金退款+其他现金存入−其他现金取出。实际盘点现金−应有现金=差额；正数长款，负数短款。存取款或差额必须备注。刷卡、扫码、其他方式和对应退款单列。模拟金额不进入真实收入或应有现金；当前系统仍为 mock。

每次保存是整日快照，不是独立班次累计，同日记录不能相加。记录不可覆盖或删除，可重新核对保存新快照。保存员工填写姓名、授权设备、门店、统计时区、金额和备注；不自动执行任何支付/退款。订单有更新需重新核对，重试相同请求编号不会重复保存。

导入的旧记录与缺少日期的历史调整会提示人工核对，不静默并入。交班记录纳入本店完整数据备份。专用厨房和顾客设备不能访问。本功能不改变营业开关或归档状态。
