# 手动收款准备

线上继续使用 PAYMENT_MODE=mock；本次没有切换营业模式。正式使用前由店主明确要求切换为 manual，然后部署并刷新所有设备。

manual 模式：顾客提交为待付款，实收为零。收银员确认现金或独立刷卡机已到账后，在收款窗口确认；POS 直接点单也必须二次确认。系统只登记收款，不连接刷卡机，不自动扣款。

正式已付款订单不允许直接作废。管理员先通过原方式实际退款，再登记退款并填写原因；系统记录原付款方式、退款金额、时间和原因，厨房同步撤下。当前仅支持整单退款。

模拟订单标为 Simulation / 模拟，模拟实收为零，不计入正式营业额。正式模式待收款区不显示旧模拟待付款单，历史仍保留并标识模式。POS、管理后台、历史区分待付款、确认实收、模拟付款和登记退款。

本地验证：58918 端口启动 Wrangler，并覆盖 PAYMENT_MODE:manual；运行 tests/manual-payments.cjs 和 tests/manual-pos.cjs。线上不运行真实收退款测试。
