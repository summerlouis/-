# 多门店管理

当前原网址和所有历史数据保留为一号店。根门店的管理设备为老板设备；分店管理配对码仅管理本店。

进入管理后台 → 门店管理：填写名称和地址，选复制菜单的来源，创建门店。默认暂停营业，配对设备并检查菜单后开启。

新店生成独立的 `/s/shop-xxxxxxxx/` 点餐、POS、厨房、后台入口和本地点餐二维码。创建时显示本店管理、收银、厨房三个配对码，请保存；后续在本店设备权限中重置。先打开本店链接再配对，不要使用一号店入口配对分店。

复制的是商品、价格、上下架、售罄、套餐、图片与语言设置；不复制订单、设备授权和收入。之后两店独立调整。页面顶部显示本店名称。老板可通过快速切换或各店入口管理，汇总明确区分真实有效收款、退款和模拟金额。

订单、厨房通知、取餐号、归档、权限、语言及浏览器购物车均按门店隔离。新店取餐号从 0001 开始；原店旧取餐号不变。暂停营业阻止创建新订单，原订单仍可处理。

当前 PAYMENT_MODE 仍为 mock：多门店功能不会开启真实收款。全部门店汇总是累计数据；单店历史入口保留日期与归档查询。

迁移：先备份，再执行 drizzle/0009_stores.sql（含 ALTER，不能重复执行），然后部署 worker。测试 tests/stores.cjs 仅对本地数据库创建测试门店。
