# 设备权限与售罄功能

后台“设备权限”：查看角色、有效期和最近使用时间；重命名为“厨房 iPad”等；撤销丢失设备；更换管理/收银/厨房配对码。

一个浏览器是一台设备，旧会话在下一次访问时登记。撤销立即阻止后续接口请求，并关闭该设备的实时连接；不会远程擦除屏幕已经显示的数据。当前管理设备不能撤销自己，可使用退出配对。更换配对码不踢出已经授权的设备；丢失设备需要单独撤销。新码只显示一次，需自行保存，之前本机的配对码文件不会自动更新。

商品管理：“标记售罄”停止新下单，“恢复销售”重新开卖。售罄独立于上下架，不删除商品。售罄商品保留显示并禁用选择；已提交但未付款订单结算时也会检查是否仍可售。已付款和厨房进行中的订单不取消。为避免未补货自动开卖，售罄不会在午夜自动恢复。

本功能继续使用现有 D1 与 Worker，不启用 R2，仍为模拟付款。
